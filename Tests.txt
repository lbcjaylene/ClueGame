
ClueGame - Test Selection Explanation

(Jaylene)

testRoomNames():

We tested several room names from our Minecraft-themed setup file,
including Enchantment Room, Trial Chambers, Stronghold, Ancient City,
and End City. We also tested Walkway and Unused to make sure the program
correctly reads both room and space entries

testBoardDimensions():

We tested that our board contains 22 rows and 23 columns. These values 
match the dimensions of our ClueLayout.csv file and verify that the program
reads the entire layout correctly
